# Sistema POS — Papel y Luna (MVP 2)

Sistema de Punto de Venta (POS) para papelería y miscelánea desarrollado como parte de la asignatura Desarrollo de Aplicaciones Web. Esta versión (MVP 2) consume un servicio externo en Google Sheets a través de Google Apps Script.

## 🚀 Características del Proyecto
* **Gestión de Ventas:** Inicio de venta, carrito dinámico, cálculo de cambio y emisión/cierre de ventas.
* **Ventas Abiertas:** Posibilidad de guardar ventas en estado abierto y retomarlas posteriormente para su cobro.
* **Módulo de Compras:** Registro de compras a proveedores con incremento automático de stock y actualización de costos de adquisición.
* **Gestión de Entidades (CRUDs):** Administración completa de Categorías, Clientes y Proveedores con validaciones de integridad referencial.
* **Integración Backend:** Conexión asíncrona (fetch, async/await) con Google Sheets usando Google Apps Script.
* **Interfaz Adaptativa:** Diseño responsive con soporte para modo claro y modo oscuro.

---

## 🛠️ Instrucciones para Ejecución Local

1. Clonar el repositorio o extraer los archivos del proyecto.
2. Abrir la carpeta raíz en un servidor web local (por ejemplo, usando la extensión **Live Server** de Visual Studio Code).
3. Abrir `index.html` en el navegador.

*Nota: No requiere instalación de dependencias de Node.js ni procesos de compilación adicionales.*
